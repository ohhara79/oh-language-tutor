# Lower opacity floor to 10% and switch slider to 10% steps

## Context

The opacity slider currently ranges from 30%–100% with a 5% slider step (the
±buttons already jump by 10%). Widen the range to 10%–100% and use a uniform
10% step so dragging the slider matches the step buttons.

## Changes

### `tutor/templates/index.html` (line 44)

Update the `<input type="range" id="opacity-slider">` attributes:

- `min="30"` → `min="10"`
- `step="5"` → `step="10"`

(`max="100"` and `value="100"` unchanged.)

### `tutor/static/app.js` (opacity block at lines 192–213)

Replace the hardcoded floor `30` with `10` in three spots:

- Line 193 (`applyOpacity`): `Math.max(30, ...)` → `Math.max(10, ...)`
- Line 197 (`applyOpacity`): `opacityMinus.disabled = v <= 30` → `v <= 10`
- Line 202 (`stepOpacity`): `Math.max(30, ...)` → `Math.max(10, ...)`

The ±10 step deltas at lines 212–213 already match the requested step size — no
change needed. `cfgGet('pageOpacity')` reads a stored value; `applyOpacity`
clamps it on load, so any old value ≥30 continues to apply unchanged.

4. Reload and confirm the chosen opacity persists (config round-trip).
