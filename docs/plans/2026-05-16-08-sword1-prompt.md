# Add `sword1` source prompt mirroring `bladerunner`

## Context

The tutor already has a Blade Runner (1997) source configured via two
data files: `extras/bladerunner.md` (system-prompt overlay with cast,
format, flavor, no-spoilers) and `scripts/bladerunner.sh` (launcher
that pipes `scummvm` stdout through `main.py`).

The user wants the same setup for **Broken Sword 1 (Circle of Blood)**,
running under the ScummVM engine at `/home/ohhara/work/scummvm/engines/sword1`.

Adding a new source is purely data-driven — no Python changes. The base
prompt builder at `tutor/prompts.py:65-72` appends whichever file is
passed to `--extra-system-prompt`, so we just need a new
`extras/sword1.md` plus a `scripts/sword1.sh` launcher.

## Engine facts (used to write the overlay)

Verified from `/home/ohhara/work/scummvm/engines/sword1/`:

- **Dialog format on stdout** — emitted at `logic.cpp:1261`:
  `debug("%d: \"%s\"", id, logText.c_str())` → lines look like
  `<numeric_id>: "<text>"`. Same shape as bladerunner, so the existing
  `--filter-regex '^\w+: "'` works unchanged.
- **Stable named IDs** (`sworddefs.h:182-190`):
  - 2162689 = SAM
  - 8388608 = PLAYER / GEORGE
  - 8454144 = NICO
  - 8585216 = BENOIR
  - 8716288 = ROSSO
  - 8781824 = DUANE
  - 9502720 = MOUE
  - 9568256 = ALBERT
- **Other speakers** (Maguire, Khan, Guido, Pearl, Cleve, Bull, Arto,
  Renée, Marquet, Lobineau, Lady Piermont, Sean, Eklund, etc.) appear
  with large runtime compact IDs that aren't enumerated in C++. The
  prompt tells the model to infer those from dialog context and notes
  that the same id stays stable per scene.
- **Engine noise to skip** — `Sound::addToQueue:`, `Sound::startSpeech:`,
  `Could not open speech.lis`, `Could not find room %d in speech.lis`,
  `Using FLAC/Vorbis/MP3/uncompressed Speech Cluster`, generic
  `WARNING:`/`ERROR:`/`DEBUG:` prefixes, resource-loading and savegame
  messages.

## Files to create

### 1. `extras/sword1.md` (new)

Mirror the section structure of `extras/bladerunner.md`:

- **SOURCE** — Broken Sword: The Shadow of the Templars (1996, Revolution
  Software). Player is George Stobbart, an American tourist in Paris
  caught in a Templar conspiracy.
- **RAW LINE FORMAT** — `<numeric_id>: "<text>"`; identical consecutive
  lines are de-duped by the engine.
- **CAST TABLE** — the eight IDs from `sworddefs.h` above, with a note
  that other speakers appear as large numeric IDs and must be inferred
  from dialog content; same id stays mapped to the same character
  within a scene.
- **NOISE TO SKIP** — patterns listed above; `WARNING:` / `ERROR:` /
  `DEBUG:` prefixes; lines that are filenames, hex digests, or byte
  counts; ScummVM/SDL startup banners.
- **FLAVOR** — 1990s point-and-click adventure register. George's voice
  is wry, ironic, mid-Atlantic; Nico is dry, French-accented English;
  British scriptwriting humor (Charles Cecil / Revolution). Vocabulary
  touches: Templar, Baphomet, manuscript, gendarme, costumier, café,
  IRA, Syria, Spain, Scotland. Call out British vs. American idiom
  mismatches Korean learners may miss.
- **NO SPOILERS** — Broken Sword has real twists worth protecting: who
  turns out to be neo-Templar / a villain, late-game betrayals, the
  identity behind the masked assassin, the manuscript's true meaning,
  the ending. Franchise references (sequels, Director's Cut additions,
  Cecil interviews) are welcome when they illuminate a word or idiom,
  but must not reveal plot beats the player has not yet reached.

### 2. `scripts/sword1.sh` (new)

Copy of `scripts/bladerunner.sh` with two paths swapped:

```bash
#!/bin/bash

scummvm 2>&1 | \
    uv run --frozen --no-dev main.py \
        --source-language English \
        --target-language Korean \
        --level intermediate \
        --extra-system-prompt extras/sword1.md \
        --filter-regex '^\w+: "' \
        --state-dir state/sword1 \
```

Make executable (`chmod +x`).
