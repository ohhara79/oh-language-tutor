# docs/rules

Topic-specific agent rules for oh-language-tutor.

`CLAUDE.md` at the repo root is the always-on index — it is loaded into every
agent session automatically. Files here are read on demand when the relevant
topic comes up. When a rule outgrows ~5 lines or is situational, put it in its
own `<topic>.md` here and link it from `CLAUDE.md`.
